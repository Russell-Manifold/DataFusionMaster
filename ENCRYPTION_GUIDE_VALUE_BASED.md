# How to Encrypt Your Claude API Key in Web.config

This guide shows you how to encrypt your API key so it's stored as `enc:...` in Web.config, and automatically decrypted at runtime.

## Step 1: Get Your Encrypted API Key

You have two options:

### Option A: Use Visual Studio (Recommended)

1. Open `SBMS\Classes\EncryptApiKeyUtility.cs`
2. On line 15, replace `"sk-ant-YOUR_API_KEY_HERE"` with your actual Claude API key
   
   **Before:**
   ```csharp
   string plainApiKey = "sk-ant-YOUR_API_KEY_HERE";
   ```
   
   **After:**
   ```csharp
   string plainApiKey = "sk-ant-v7m8x9y2z1a3b4c5d6e7f8g9h0i1j2k3";
   ```

3. Right-click on `EncryptApiKeyUtility.cs` and select **"Run Custom Tool"** or build the project
4. The encrypted key will appear in the Output window
5. **Copy the encrypted value** (it starts with `enc:`)

### Option B: Use PowerShell

Save this as `encrypt-key.ps1` and run it:

```powershell
Add-Type -Path "H:\Manifold\SBMS_v2\SBMS\bin\SBMS.dll"

$plainKey = "sk-ant-YOUR_API_KEY_HERE"
$encrypted = [SBMS.Classes.ConfigEncryptionHelper]::EncryptValue($plainKey)
Write-Host "Encrypted Key: $encrypted"
```

## Step 2: Update Web.config

1. Open `SBMS\Web.config`
2. Find the `<claudeSettings>` section:
   ```xml
   <claudeSettings>
       <add key="ClaudeApiKey" value="sk-ant-YOUR_API_KEY_HERE" />
       ...
   </claudeSettings>
   ```

3. Replace the `ClaudeApiKey` value with your encrypted key:
   ```xml
   <claudeSettings>
       <add key="ClaudeApiKey" value="enc:AgvRm4kcN3p9X..." />
       ...
   </claudeSettings>
   ```

4. **Save** Web.config

## Step 3: Done! ?

Your application will automatically:
- ? Read the encrypted value from Web.config
- ? Detect the `enc:` prefix
- ? Decrypt it at runtime
- ? Use the plain API key to call Claude

## How It Works

**In Web.config (encrypted):**
```xml
<add key="ClaudeApiKey" value="enc:AgvRm4kcN3p9X2..." />
```

**At runtime (automatically decrypted):**
```csharp
// ChatService reads this:
string apiKey = ConfigurationManager.AppSettings["ClaudeApiKey"];
// Value: "enc:AgvRm4kcN3p9X2..."

// ConfigEncryptionHelper automatically decrypts it:
string decrypted = ConfigEncryptionHelper.DecryptValue(apiKey);
// Value: "sk-ant-v7m8x9y2z1a3b4c5d6e7f8g9h0i1j2k3" ?
```

## Security Notes

? **Encrypted at rest:** The value in Web.config is encrypted  
? **Decrypted in memory:** Only decrypted when actually needed  
? **Static key:** Uses AES-256 encryption with a pre-defined key  
? **Not perfect but better:** Better than plain text, but not as secure as Azure Key Vault  

## To Change/Update the Key

If you need to update your Claude API key:

1. Get a new encrypted value (repeat Step 1)
2. Update Web.config with the new encrypted value
3. Restart your application
4. Done! ?

## Troubleshooting

**Q: I see an error "Failed to decrypt configuration value"**
- Make sure you copied the entire encrypted value including the `enc:` prefix
- Make sure the value is exactly as generated by the encryption utility

**Q: The plain API key is visible in Visual Studio when editing EncryptApiKeyUtility.cs**
- Yes, you'll see it briefly while editing—that's normal
- Once encrypted and stored in Web.config, it's hidden
- After encrypting, you can delete or clear the plain text from EncryptApiKeyUtility.cs

**Q: Can I encrypt other settings?**
- Yes! Use the same pattern:
  ```csharp
  string encrypted = ConfigEncryptionHelper.EncryptValue("your-plain-value");
  // Store in Web.config as: value="enc:..."
  // Read with: ConfigEncryptionHelper.DecryptValue(value)
  ```
